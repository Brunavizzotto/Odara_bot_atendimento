# Odara Bot de Atendimento 

Este repositório contém o código-fonte e a documentação do **bot de atendimento automatizado** desenvolvido para um cliente do setor de alfajores. 

## Contexto do Projeto
Este projeto é originado e desenvolvido no âmbito das atividades práticas da residência tecnológica interna **HBR**, com foco em inovação, desenvolvimento de software e soluções voltadas para o mercado real.

## Objetivo
Criar um canal de atendimento inteligente, ágil e humanizado para otimizar os pedidos, tirar dúvidas frequentes e melhorar a experiência dos clientes de alfajores, integrando automação aos processos comerciais da marca.
